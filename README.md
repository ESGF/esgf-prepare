# esgprep

`esgprep` is a toolbox to prepare data for ESGF publication.

## Requirements

`esgprep` depends directly on
[`esgvoc`](https://github.com/ESGF/esgf-vocab), together with other Python
packages. Python dependencies are installed automatically during installation.

Additional system dependencies may need to be installed separately. See the
documentation for detailed requirements.

## Installation

`esgprep` is available from PyPI and can be installed with:

```bash
pip install esgprep
```

See the [installation documentation](https://esgf.github.io/esgf-prepare/installation.html)
for more details and other installation options.
